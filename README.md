# 프롬프트 가이드 (prompt-guide)

강사가 수업용 프롬프트를 프로젝트·단계별로 미리 만들어 두고, 수업 중에 한 단계씩 공개하며 진행하는 실시간 수업 도구입니다. 학생들은 링크로 입장해 강사가 공개한 단계까지의 프롬프트를 보면서 따라 합니다.

## 사용 방법

### 강사 (작업실)
1. 새 프로젝트를 만들고 프롬프트를 단계별로 등록합니다.
2. 수업 시작을 누르면 학생 입장용 화면이 열립니다.
3. 수업 중 이전 / 다음 페이지 버튼으로 단계를 하나씩 공개합니다.

### 학생
1. 강사가 안내한 주소로 접속해 입장합니다. (익명 입장 가능)
2. 강사가 공개한 단계의 프롬프트를 보고 복사해서 사용합니다.

## 기술 구성

- 단일 `index.html` — HTML/CSS/JS (프레임워크 없음)
- Firebase Realtime Database — 강사의 단계 공개가 학생 화면에 즉시 반영
- 정적 호스팅(Vercel 등)으로 바로 배포할 수 있습니다.
